# Offline-Falleditor V3.0.6 – GitHub Pages

Diese Dateien direkt in ein GitHub-Repository legen und GitHub Pages für den Branch aktivieren.

Der Editor läuft vollständig statisch im Browser. Er exportiert Fälle als `*.vitasimexport`. Die Datei anschließend im VitaSim-Falleditor am Raspberry Pi über **Offline-Fall importieren (.vitasimexport)** laden und dort mit **Vorlage speichern** übernehmen.

Enthalten sind dieselben Datenbereiche wie im aktuellen VitaSim-Falleditor: Grunddaten, Ausgangswerte, ereignisgesteuerte Fallentwicklung (4 Standardreaktionen + eigene Ereignisse), Nur-Dokumentation-Ereignisse, Lernziele, CRM-Beobachtung, Fallvarianten und Fallbilder.
