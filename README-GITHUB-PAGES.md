# Offline-Falleditor V3.1.12

GitHub-Pages-/Offline-Version passend zu VitaSim V3.2.0.

Änderungen:
- PIN-Sperre wieder aktiv (Standard-PIN `0000`).
- Vorerkrankungen, Medikation und Risikofaktoren ausschließlich über SAMPLE(R).
- Ältere Dateien werden beim Öffnen automatisch nach SAMPLE M/P/R migriert.
- SAMPLE(R) und OPQRST neu gestaltet.
- Vorschlagsauswahl plus Freitext für Allergien, Medikation, Patientenvorgeschichte und Risikofaktoren.
- Fallbilder und Fallvarianten als eigene, farblich getrennte Bereiche.
- `.vitasimexport` bleibt das bevorzugte Austauschformat; JSON-Import für iPhone/iPad bleibt erhalten.
