# VitaSim Falleditor: Pi- und Word-Vorlage

- **Pi-Vorlage**: bisheriger vollständiger Editor; `.vitasimexport` für VitaSim V3.20.0.
- **Word-Vorlage**: Einsatzmeldung, 3S, Ausbildungsplanung, ABCDE, initiale Vitalwerte, SAMPLE(R), OPQRST und Ausbilderinformationen. Export als `.docx`, Druck/PDF oder Einsatzmeldung `.png`.
- Gemeinsame Felder werden in beide Richtungen synchronisiert.
- **Editor-Projekt speichern** (`.vitasimprojekt`) erhält auch Word-Zusatzfelder.
- Word-spezifische Felder fließen nicht in die Pi-Falllogik ein.

GitHub Pages: Inhalt des Ordners ins Repository übernehmen. Offline-Cache wurde aktualisiert. Ein kompletter Praxistest im Browser und am Pi steht aus.
